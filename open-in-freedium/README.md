# <img src="./src/icon.svg" height="25" width="25"> Open in Freedium URL Button

<a href="https://addons.mozilla.org/firefox/addon/freedium-page-action-button"><img src="../toggle-github-dev/screenshots/get-the-addon-129x45px.8041c789.png"></a>

This simple Firefox addon adds a URL button to quickly open current page on Freedium. The button is shown only on Medium, Bloomberg and NY Times pages. Clicking icon with middle mouse button will open Freedium in a new tab.
